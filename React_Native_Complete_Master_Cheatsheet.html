1. Primitives & Flexbox Architecture
Phase 1: Foundations

React Native does not use HTML DOM (<div>, <span>). It compiles directly to native host views (UIView on iOS, ViewGroup on Android). Default flex direction is always column.

🗣️ Tenglish: React Native lo HTML div undadu; `View` and `Text` vadatham. By default `flexDirection: column` untundi (Top to Bottom). Notch and Home bar lopala content padakunda `SafeAreaView` vadali. 
import React from 'react';
import { View, Text, Image, Pressable } from 'react-native';
import { SafeAreaProvider, SafeAreaView } from 'react-native-safe-area-context';

export const Level1Primitives = () => (
  <SafeAreaProvider>
    <SafeAreaView>
      <View>
        <Text>React Native Primitive Tree</Text>
        <Image source={{ uri: 'https://reactnative.dev/img/tiny_logo.png' }} />
        <Pressable onPress={() => console.log('Tapped!')}>
          <Text>Tap Here</Text>
        </Pressable>
      </View>
    </SafeAreaView>
  </SafeAreaProvider>
);
2. Virtualized Lists & Keyboard Handling
Phase 1: Foundations

ScrollView mounts all children in RAM at once. FlatList recycles cells outside the viewport to prevent OOM crashes. Use KeyboardAvoidingView to prevent keyboards from hiding inputs.

🗣️ Tenglish: ScrollView lo 10,000 items pedithe app crash avthundi. FlatList screen meeda kanipinche items ni mathrame RAM lo unchi migilivativi recycle chesthundi (Virtualization). 
import React from 'react';
import { FlatList, Text, TextInput, KeyboardAvoidingView, Platform } from 'react-native';

export const Level2Lists = ({ items }) => (
  <KeyboardAvoidingView behavior={Platform.OS === 'ios' ? 'padding' : 'height'}>
    <FlatList
      data={items}
      keyExtractor={(item) => item.id.toString()}
      renderItem={({ item }) => <Text>{item.title}</Text>}
      initialNumToRender={10}
      maxToRenderPerBatch={5}
      windowSize={5}
      removeClippedSubviews={true}
    />
    <TextInput placeholder="Type here..." />
  </KeyboardAvoidingView>
);
3. Mobile React Hooks, AppState & Memory Leaks
Phase 1: Foundations

Mobile apps pause and resume via AppState (active vs background). Clean up all intervals and event listeners in useEffect return callbacks to avoid silent memory leaks.

🗣️ Tenglish: User Home screen ki vellinappudu (`background`), GPS timers and subscriptions stop cheyali. `useEffect` cleanup function lo unsubscribe cheyakapothe battery drain and memory leaks vasthayi. 
import React, { useState, useEffect, useRef } from 'react';
import { Text, AppState } from 'react-native';

export const Level3Lifecycle = () => {
  const [appState, setAppState] = useState(AppState.currentState);
  const timerRef = useRef(null);

  useEffect(() => {
    const sub = AppState.addEventListener('change', (next) => setAppState(next));
    timerRef.current = setInterval(() => console.log('Heartbeat'), 1000);

    return () => {
      sub.remove();
      clearInterval(timerRef.current); // 🛑 Garbage collection cleanup
    };
  }, []);

  return <Text>Current App State: {appState}</Text>;
};

5. Networking, Interceptors & Hardware Keystores
Phase 2: Core Architecture

Never store sensitive JWT tokens in unencrypted AsyncStorage. Use expo-secure-store (iOS Keychain & Android Keystore). Axios response interceptors auto-refresh 401 expired tokens silently.

🗣️ Tenglish: Passwords and Auth JWT tokens eppudu `SecureStore` (Hardware Keychain) lo pettali. 401 Token expire avvagane user ki theliyakunda auto ga new token fetch chesi retry chestham. 
import axios from 'axios';
import * as SecureStore from 'expo-secure-store';

const api = axios.create({ baseURL: 'https://api.myapp.com' });

api.interceptors.request.use(async (config) => {
  const token = await SecureStore.getItemAsync('user_jwt');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

api.interceptors.response.use(
  (res) => res,
  async (err) => {
    if (err.response?.status === 401) {
      // Refresh token logic
      const newToken = await fetchNewToken();
      await SecureStore.setItemAsync('user_jwt', newToken);
      return api(err.config); // Retry original request
    }
    return Promise.reject(err);
  }
);
6. Global State (Zustand) & MMKV Storage
Phase 2: Core Architecture

Zustand provides boilerplate-free atomic state selection without context re-render cascades. MMKV provides synchronous, C++ JSI direct memory key-value storage (30x faster than AsyncStorage).

🗣️ Tenglish: Redux laga pedda boilerplate lekunda Zustand tho clean global state rayochu. MMKV storage C++ memory vaadi 0ms synchronous speed tho save chesthundi. 
import { create } from 'zustand';
import { MMKV } from 'react-native-mmkv';

const storage = new MMKV();

export const useUserStore = create((set) => ({
  user: null,
  login: (userData) => {
    storage.set('user_profile', JSON.stringify(userData));
    set({ user: userData });
  },
  logout: () => {
    storage.delete('user_profile');
    set({ user: null });
  },
}));
7. Gestures & 60 FPS UI Thread Animations (Reanimated 3)
Phase 3: Native & Polish

Animations must run on the UI Thread via Worklets without crossing the JS bridge. react-native-reanimated + GestureHandler delivers 60–120 FPS buttery smooth physics.

🗣️ Tenglish: Animations JavaScript thread meeda run aithe phone hang avthundi. Reanimated 3 direct ga Native UI Thread meeda 60 FPS tho animations run chesthundi (`runOnUI`). 
import React from 'react';
import Animated, { useSharedValue, useAnimatedStyle, withSpring } from 'react-native-reanimated';
import { Gesture, GestureDetector } from 'react-native-gesture-handler';

export const Level7Gesture = () => {
  const translateX = useSharedValue(0);

  const pan = Gesture.Pan()
    .onChange((e) => {
      translateX.value = e.translationX;
    })
    .onEnd(() => {
      translateX.value = withSpring(0);
    });

  const animatedStyle = useAnimatedStyle(() => ({
    transform: [{ translateX: translateX.value }],
  }));

  return (
    <GestureDetector gesture={pan}>
      <Animated.View style={animatedStyle}>
        <Animated.Text>Swipe Me!</Animated.Text>
      </Animated.View>
    </GestureDetector>
  );
};

import * as Location from 'expo-location';
import * as Haptics from 'expo-haptics';

export const triggerHardwareActions = async () => {
  // 1. Tactile Vibration
  await Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium);

  // 2. Hardware GPS Coordinates
  const { status } = await Location.requestForegroundPermissionsAsync();
  if (status === 'granted') {
    const loc = await Location.getCurrentPositionAsync({});
    console.log('User GPS:', loc.coords.latitude, loc.coords.longitude);
  }
};

11. Real-Time Push Notifications & Deep Linking
Phase 3: Native & Polish

Dual-layer token architecture (Expo Push Token relays to APNs/FCM). Background tap listeners and cold-start handlers (getLastNotificationResponseAsync) route to screens via top-level navigationRef.

🗣️ Tenglish: Push token phone address laga. Lock screen nunchi notification tap chesi app open chesinappudu `navigationRef` vaadi direct ga ఆ specific screen ki route chestham. 
import * as Notifications from 'expo-notifications';
import { createNavigationContainerRef } from '@react-navigation/native';

export const navigationRef = createNavigationContainerRef();

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowAlert: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
});

export const setupNotificationTapListener = () => {
  Notifications.addNotificationResponseReceivedListener((response) => {
    const data = response.notification.request.content.data;
    if (data?.screen && navigationRef.isReady()) {
      navigationRef.navigate(data.screen, { id: data.id });
    }
  });
};
12. Offline-First Architecture & SQLite Databases
Phase 3: Native & Polish

expo-sqlite stores relational data on disk using B-Trees (~0.5ms queries). Optimistic UI renders actions instantly (⏳), queues requests in SQLite, and drains upon NetInfo reconnection (✅).

🗣️ Tenglish: Airplane mode lo unnapudu comment post chesthe: screen meeda instant ga chupistham (⏳), SQLite queue lo store chesi, internet raagane NetInfo detect chesi server ki push chestham (✅). 
import * as SQLite from 'expo-sqlite';
import NetInfo from '@react-native-community/netinfo';

export const initOfflineDB = async () => {
  const db = await SQLite.openDatabaseAsync('offline_app.db');
  await db.execAsync(`
    CREATE TABLE IF NOT EXISTS queue (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      endpoint TEXT,
      body TEXT,
      is_synced INTEGER DEFAULT 0
    );
  `);
  return db;
};

export const syncQueue = async (db) => {
  const pending = await db.getAllAsync('SELECT * FROM queue WHERE is_synced = 0;');
  for (const item of pending) {
    // Send to backend API
    await db.runAsync('UPDATE queue SET is_synced = 1 WHERE id = ?;', [item.id]);
  }
};

14. Over-The-Air (OTA) Live Updates & Rollback Strategies
Phase 4: Production & CI/CD

Decouples the JavaScript bundle from the native binary shell. Push live bug fixes in ~5 seconds via eas update. runtimeVersion locks updates to compatible native binaries. Emergency rollbacks in 1s via eas update:republish.

🗣️ Tenglish: 3-day App Store review delay lekunda, JavaScript bug fixes ni `eas update` dwara 5 seconds lo live ga push cheyochu. Production lo sudden bug vasthe `eas update:republish` dwara 1 second lo rollback chestham. 
import * as Updates from 'expo-updates';

export const checkAndApplyLiveUpdates = async () => {
  try {
    const update = await Updates.checkForUpdateAsync();
    if (update.isAvailable) {
      await Updates.fetchUpdateAsync();
      await Updates.reloadAsync(); // ⚡ Instant live update applied!
    }
  } catch (err) {
    console.log('Update error:', err);
  }
};

// Emergency CLI Rollback Command:
// eas update:republish --group-id <stable-working-group-id>
